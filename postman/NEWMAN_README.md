# Postman and Newman

Use `postman/HustleHubPlus_Part2_Full.postman_collection.json` (collection format v2.1). Run only against your local API and database with both running. In Postman, File > Import and choose the collection, then Run collection in order.

**Important:** The collection registers sample users. Before a new run, set new unique `freelancerEmail` and `clientEmail` collection variables or remove the previous example records. The default password is only for nonproduction demo accounts and must never be used for real accounts. Registration is expected to return `201` on the first run; duplicated emails will correctly return `409`.

```powershell
npm install -g newman
newman run .\postman\HustleHubPlus_Part2_Full.postman_collection.json --reporters cli,json --reporter-json-export .\evidence\newman-results.json
```

The JSON results must be generated by you from a real successful run. Do not submit a screenshot of an unexecuted collection as evidence. Postman Collection v2.1 is compatible with Newman; newer collection v3 features are not.
